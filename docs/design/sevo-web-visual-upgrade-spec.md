# SEVO Web 控制台视觉优化 — 截图级

OpenClaw（pm-01 子Agent）  
2026-05-18

## 目标

把 SEVO Web 控制台的视觉质量从 6/10 提升到 8-9/10，使仪表盘、项目页、交付物页的截图可直接作为官网 hero 图素材。

参考风格：Linear、Vercel Dashboard — 深色背景、精致卡片、清晰层级、克制用色。

## 约束

- 只改 CSS / Tailwind 样式 + 前端组件展示层 + 种子数据
- 不改后端逻辑（engine-service.ts 的函数签名和 API 路由逻辑不变）
- 不改路由结构、不新增页面
- 种子数据可增加条目数量和丰富度，但不改数据结构（TypeScript 类型不变）
- 保持现有 shadcn/ui 组件库，可扩展样式但不引入新 UI 库

## 验收标准（全局）

- ux-01 对仪表盘、项目页、交付物页分别截图评分 ≥ 8/10
- 截图放到官网 hero 区不丢人（专业 SaaS 产品感）
- 深色主题统一，无明显色彩冲突
- 移动端不崩溃（响应式基本可用即可，不要求移动端完美）

## FR-01：全局深色主题统一

### 描述

将整个控制台（侧边栏 + 顶栏 + 主内容区）统一为深色主题，参考 Linear/Vercel 的暗色调。当前侧边栏已是深色（slate-900），但主内容区是白色背景，视觉割裂。

### AC

- AC-01-1：主内容区背景从白色切换为深色（推荐 `hsl(220, 13%, 8%)` ~ `hsl(225, 15%, 10%)` 范围）
- AC-01-2：顶栏背景与主内容区融合，去掉白色背景和 `shadow-sm`，改为深色 + 底部细线分隔
- AC-01-3：所有卡片（Card 组件）背景改为略浅于背景的深色（如 `hsl(220, 13%, 12%)`），边框改为 `border-white/5` ~ `border-white/8` 的微透明白边
- AC-01-4：文字颜色层级：标题用 `text-white` 或 `text-slate-100`；正文用 `text-slate-300`；辅助文字用 `text-slate-500`
- AC-01-5：globals.css 的 `.dark` 变量更新为深色主题值，并在 `<html>` 标签默认加 `dark` class
- AC-01-6：侧边栏保持现有深色风格，微调使其与新主内容区背景协调（可能需要略微调深或加边界线）
- AC-01-7：所有 Badge/状态标签在深色背景下可读性良好（对比度 ≥ 4.5:1）

### 改动范围

- `app/globals.css`：更新 CSS 变量
- `app/layout.tsx` 或 `app/(dashboard)/layout.tsx`：确保 dark class 生效
- `components/app-shell.tsx`：顶栏样式调整
- `components/ui/card.tsx`：卡片默认样式
- `components/ui/stat-card.tsx`：数值卡片样式
- `components/ui/badge.tsx`：Badge 在深色下的可读性

## FR-02：仪表盘视觉升级

### 描述

仪表盘是截图主画面，需要最强视觉冲击力。数据卡片要有质感（渐变、光泽、阴影），图表要精致，整体要传达"系统正在高效运转"的感觉。

### AC

- AC-02-1：KPI 卡片（StatCard）升级 — 加入微渐变背景（从卡片底色到略亮色的 5% 渐变）、更精致的阴影（多层 box-shadow）、hover 时有光泽效果
- AC-02-2：KPI 数值字号加大到 `text-4xl` 或 `text-5xl`，使用 tabular-nums 等宽数字，数值颜色根据语义用品牌色（健康度用绿色、阻塞用琥珀色等）
- AC-02-3：阶段分布图表区域视觉增强 — 图表背景加微妙网格或渐变，柱状图/饼图颜色更鲜艳饱和（在深色背景下需要更高饱和度）
- AC-02-4：HealthGauge 组件视觉升级 — 加入发光效果（glow）或渐变弧线，使其成为视觉焦点
- AC-02-5：页面顶部健康状态 pill 改为更醒目的样式（可加脉冲动画表示系统活跃）
- AC-02-6：种子数据调整 — 确保仪表盘展示时有足够数据密度：总 FR ≥ 12，各阶段都有分布，健康度在 75-85% 之间（既不完美也不糟糕，最有信息量）
- AC-02-7：底部状态卡片行（失败/阻塞/推进中/已完成）加入左侧彩色竖条或图标背景色块，增强状态语义的视觉区分

### 改动范围

- `app/(dashboard)/dashboard/page.tsx`：布局和样式类调整
- `components/ui/stat-card.tsx`：卡片视觉升级
- `components/ui/health-gauge.tsx`：仪表盘组件升级
- `lib/engine-service.ts`：种子数据丰富度调整（只改数据量，不改结构）

## FR-03：项目页卡片化升级

### 描述

项目列表从当前的列表式改为更有视觉冲击力的卡片布局。每个项目卡片要像一个独立的"项目仪表盘缩略图"，状态一目了然。

### AC

- AC-03-1：项目卡片改为网格布局（桌面端 2 列或 3 列），每张卡片高度统一，内部信息密度适中
- AC-03-2：状态 Badge 改为彩色实心 badge（不是 outline），颜色饱和度在深色背景下足够醒目：风险=红色、推进中=蓝色、稳定=绿色
- AC-03-3：每张卡片加入微型进度环或进度条，直观展示完成比例
- AC-03-4：卡片 hover 效果：边框发光（glow）+ 微上移 + 阴影加深
- AC-03-5：种子数据补充 — 确保至少有 3 个项目（当前已有 sevo/kivo/claw-design），每个项目有不同状态（一个稳定、一个推进中、一个有风险），FR 数量各不相同
- AC-03-6：卡片内的"项目进度"区块视觉升级 — 进度条改为渐变色（绿色渐变），背景改为深色适配

### 改动范围

- `app/(dashboard)/projects/page.tsx`：布局从列表改为网格，卡片样式升级
- `lib/engine-service.ts`：确保种子数据有 3 个不同状态的项目

## FR-04：交付物页视觉升级

### 描述

交付物列表加入文件类型图标、状态指示器和更清晰的视觉层级，让页面看起来像一个专业的制品管理系统。

### AC

- AC-04-1：每个交付物条目左侧加入彩色文件类型图标背景色块（document=蓝、code=紫、report=绿、artifact=灰），图标放在圆角色块内
- AC-04-2：交付物条目加入状态指示器 — 用小圆点或 badge 表示"已验证/待审核/草稿"状态（可从 stage 信息推断）
- AC-04-3：筛选栏视觉升级 — 深色背景下的输入框和下拉框样式适配，边框用微透明白色
- AC-04-4：统计卡片行（顶部的类型统计）视觉与仪表盘 StatCard 风格统一
- AC-04-5：交付物列表分组标题（按阶段分组）加入左侧彩色竖线或背景色带，增强分组感
- AC-04-6：种子数据确保每种类型（document/code/report/artifact）都有条目，总数 ≥ 8 条

### 改动范围

- `app/(dashboard)/deliverables/page.tsx`：条目样式、图标色块、状态指示器
- `lib/engine-service.ts`：确保交付物种子数据覆盖所有类型且数量充足

## FR-05：全局排版与间距优化

### 描述

统一字体层级、间距系统和微交互，让整个控制台有一致的节奏感。

### AC

- AC-05-1：页面标题（PageHeader）字号 `text-2xl` + `font-bold`，描述文字 `text-sm text-slate-400`，标题与内容间距 `space-y-8`
- AC-05-2：卡片内部 padding 统一为 `p-6`，卡片间距统一为 `gap-6`
- AC-05-3：所有数字使用 `font-variant-numeric: tabular-nums`（等宽数字），大数值加 `font-semibold`
- AC-05-4：页面切换动画保持现有 `fade-in`，可微调时长到 0.2s 使其更利落
- AC-05-5：滚动条样式定制 — 深色背景下用细窄的半透明滚动条（webkit-scrollbar）
- AC-05-6：全局字体确保使用系统字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", ...），中文回退到 "PingFang SC", "Microsoft YaHei"

### 改动范围

- `app/globals.css`：滚动条样式、字体栈、数字排版
- `components/ui/page-header.tsx`：标题层级
- 各页面组件：间距统一

## 实现优先级

1. FR-01（全局深色主题）— 基础，其他 FR 依赖此
2. FR-05（排版间距）— 与 FR-01 可同步做
3. FR-02（仪表盘）— 截图主画面，优先级最高
4. FR-03（项目页）— 第二截图素材
5. FR-04（交付物页）— 第三截图素材

## 技术备注

- 当前项目使用 Tailwind CSS + CSS 变量（HSL），深色主题通过 `.dark` class 切换
- shadcn/ui 组件已支持 dark mode，只需确保 CSS 变量正确
- Recharts 图表颜色需要在深色背景下重新调色（提高饱和度和亮度）
- 种子数据在 `lib/engine-service.ts` 中，是内存 mock 数据，改动无副作用
