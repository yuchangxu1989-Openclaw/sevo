# SEVO Web 控制台 UI 精简 — 产品需求规格

OpenClaw（pm-01 子Agent）
2026-05-18

## 目标

将 SEVO Web 控制台从"内部后台系统"精简为"可截图展示级别的展示型工作台"。主导航收敛到 5 个入口，其余页面隐藏或合并。改完后，任意一张截图都能放官网给外部团队看。

## 约束

- 只改前端（`web/` 目录），不改后端 API 和核心逻辑
- 保持深色主题
- 移动端适配
- 现有路由和 API 接口不删除，只隐藏入口
- 数据层不变，只改展示层

## 用户画像

- **外部展示受众**：顶级 AI 团队决策者，看截图判断产品成熟度
- **日常操作用户**：研发流水线运营者，需要快速处理风险、查看进度、审批门禁

---

## 信息架构变更

### 当前导航（6 项）

1. 仪表盘 `/dashboard`
2. 项目 `/projects`
3. 交付物 `/deliverables`
4. 通知中心 `/notifications`
5. 配置设置 `/settings`
6. 全局搜索 `/search`

另有独立页面未在主导航但可访问：FR 列表 `/frs`、评审 `/reviews`、待办 `/todos`、门禁 `/gates/[id]`、账本 `/ledger`、统计 `/analytics`

### 目标导航（5 项）

1. **总览** `/dashboard` — 唯一首页，健康度 + 流水线主视觉 + 风险队列
2. **FR 流水线** `/frs` — 核心操作页，每条 FR 的阶段、状态、风险
3. **风险与动作** `/todos` — 合并待办 + 评审 + 门禁审批
4. **产物库** `/deliverables` — 按 FR 聚合的交付成果
5. **项目** `/projects` — 项目健康对比

### 隐藏/合并的页面

| 原页面 | 处理方式 |
|--------|----------|
| 通知中心 `/notifications` | 从主导航移除，改为顶栏右上角通知图标 + 抽屉 |
| 配置设置 `/settings` | 从主导航移除，改为顶栏用户菜单下的"管理"入口 |
| 统计分析 `/analytics` | 从主导航移除，关键图表合并到总览首页 |
| 评审追踪 `/reviews` | 合并到"风险与动作"页 |
| 交付账本 `/ledger` | 合并到 FR 详情页和产物详情页 |
| 全局搜索 `/search` | 从独立页面改为顶栏命令面板（Cmd+K） |

## FR 清单

### FR-01：主导航精简为 5 项

将 `app-shell.tsx` 中的 `NAV_ITEMS` 从当前 5 项（仪表盘、项目、交付物、通知中心、配置设置）改为新 5 项（总览、FR 流水线、风险与动作、产物库、项目）。

**AC-01-1**：左侧导航只显示 5 个入口：总览、FR 流水线、风险与动作、产物库、项目。
**AC-01-2**：导航图标与标签匹配新命名。
**AC-01-3**：移动端汉堡菜单同步更新为 5 项。
**AC-01-4**：通知入口移到顶栏右上角，显示未读角标。
**AC-01-5**：配置设置入口移到顶栏用户/退出按钮旁的下拉菜单中。

### FR-02：总览首页重构

将 `/dashboard` 从数字卡片 + 列表改为三段式布局。

**AC-02-1**：顶部显示一句话系统判断（健康/有风险/阻塞），动态生成，例如"2 个 FR 等待门禁审批，1 个失败待恢复"。
**AC-02-2**：中部主视觉为 11 阶段流水线横向图，每个阶段显示当前 FR 数量，失败阶段用红色/琥珀色高亮。
**AC-02-3**：底部为风险队列，只列最多 3 个最紧急的待处理项（门禁审批、失败恢复、澄清），每项带一个主操作按钮。
**AC-02-4**：保留现有健康度百分比和项目完成率数据，但作为流水线图的辅助信息而非首屏主体。
**AC-02-5**：移动端流水线图改为纵向排列或可横向滚动。

### FR-03：FR 流水线页精简

将 `/frs` 列表从报告式改为控制台式。

**AC-03-1**：每条 FR 只显示：标题（≤40字）、当前阶段标签、状态标签（正常/失败/等待）、最近更新时间、风险原因（如有）。
**AC-03-2**：删除列表中的长文"当前判断"描述，改为短标签（如"失败待处理""等待门禁""正常推进"）。
**AC-03-3**：默认只展示异常、阻塞、推进中的 FR；已完成的 FR 折叠到底部"已完成"区域。
**AC-03-4**：保留按项目、按阶段的筛选能力。
**AC-03-5**：点击 FR 进入详情页，详情页保持现有功能不变。

### FR-04：风险与动作页（合并待办 + 评审）

将 `/todos` 页面升级为"风险与动作"，合并评审追踪内容。

**AC-04-1**：页面标题改为"风险与动作"。
**AC-04-2**：首屏分三类卡片：等待决策（门禁审批）、失败待恢复、澄清待回答。
**AC-04-3**：每条动作项只显示：标题、关联 FR、严重等级（P0-P3）、一个主操作按钮。
**AC-04-4**：从 `/reviews` 页面合并评审修复追踪数据，按严重等级排序。
**AC-04-5**：支持按严重等级筛选（P0/P1/P2/P3）。
**AC-04-6**：空态显示"当前无待处理风险"配合一个轻量插图，而非空白。

### FR-05：产物库页改造

将 `/deliverables` 从按阶段堆叠改为按 FR 聚合。

**AC-05-1**：产物按 FR 分组展示，每个 FR 下显示其最终产物列表。
**AC-05-2**：每个产物项显示：名称、类型标签、生成时间、大小、预览/下载按钮。
**AC-05-3**：首屏只展示最近 5 个高价值产物（按时间倒序），其余折叠。
**AC-05-4**：产物详情页增加"交付记录"模块（从账本页合并），显示该产物的不可篡改记录。
**AC-05-5**：空态显示"暂无交付产物"配合说明文案。

### FR-06：全局搜索改为命令面板

将独立搜索页 `/search` 改为顶栏命令面板。

**AC-06-1**：顶栏搜索框点击或 `Cmd+K` / `Ctrl+K` 触发全屏命令面板覆盖层。
**AC-06-2**：命令面板支持搜索 FR、产物、门禁、账本记录。
**AC-06-3**：搜索结果按类型分组显示，每组最多 5 条，带"查看全部"链接。
**AC-06-4**：`/search` 路由保留但不在导航中显示，作为命令面板"查看全部"的落地页。
**AC-06-5**：命令面板支持 ESC 关闭，点击结果跳转对应详情页。

### FR-07：通知抽屉

将通知中心从独立页面改为右上角抽屉。

**AC-07-1**：顶栏右上角显示通知铃铛图标，有未读时显示红色角标数字。
**AC-07-2**：点击铃铛弹出右侧抽屉，显示最近 20 条通知。
**AC-07-3**：每条通知显示：标题、时间、关联 FR（可点击跳转）。
**AC-07-4**：抽屉底部"查看全部"链接跳转 `/notifications` 完整页面（保留但不在主导航）。
**AC-07-5**：关键通知（P0/P1 风险）自动出现在"风险与动作"页。

### FR-08：视觉升级 — 深色科技风

统一视觉语言，从"后台系统"升级为"AI 基础设施产品"。

**AC-08-1**：背景色从纯黑改为近黑蓝（如 `#0a0e1a`），减少压迫感。
**AC-08-2**：主色调使用电光绿（成功/正常）和琥珀色（风险/失败），替代当前的蓝绿配色。
**AC-08-3**：卡片间距加大（从 `gap-4` 改为 `gap-6`），减少边框使用，用微妙阴影区分层级。
**AC-08-4**：标题字号拉大（`text-2xl` → `text-3xl`），正文保持 `text-sm`，拉开层级。
**AC-08-5**：所有页面保持深色主题一致性，无亮色突兀元素。

### FR-09：信息密度三层结构

所有页面统一三层信息结构。

**AC-09-1**：每个页面首屏第一层为一句话结论/状态判断。
**AC-09-2**：第二层为 2-4 个关键数字或状态指标。
**AC-09-3**：第三层为可操作列表或详细内容。
**AC-09-4**：三层之间有明确视觉分隔（间距或分割线）。

### FR-10：空态与错误态统一

所有空态和错误态页面统一处理。

**AC-10-1**：空态统一显示三件事：当前状态描述、为什么是空的、下一步建议。
**AC-10-2**：错误态统一显示：发生了什么、可能原因、重试按钮 + 返回按钮。
**AC-10-3**：门禁详情页 `/gates/[id]` 空态从只显示"重试"改为显示"门禁不存在或已结束"+ 返回按钮。
**AC-10-4**：所有空态配合一个轻量 SVG 插图（统一风格），不使用纯文字空白。

### FR-11：移动端适配

确保 5 个主页面在移动端可用。

**AC-11-1**：导航在移动端收起为底部 Tab Bar（5 个图标）或顶部汉堡菜单。
**AC-11-2**：流水线图在移动端改为纵向或可横向滚动。
**AC-11-3**：卡片在移动端单列排列，间距适当缩小。
**AC-11-4**：命令面板在移动端全屏显示。
**AC-11-5**：通知抽屉在移动端改为全屏覆盖。

## 不做的事

- 不改后端 API 接口
- 不删除任何路由（只隐藏导航入口）
- 不改数据库 schema
- 不改认证逻辑
- 不新增后端功能
- 不改 KIVO 控制台（另开 pipeline）

## 验收标准（整体）

1. 主导航只有 5 项，其余入口通过顶栏或二级页面访问
2. 总览首页有 11 阶段流水线主视觉，一眼看懂执行态
3. 任意主页面截图放到官网不违和
4. 移动端 5 个主页面可正常操作
5. 无空白页面或只有"重试"按钮的错误态
6. 深色主题一致，无亮色突兀元素
