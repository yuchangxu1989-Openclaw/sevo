# ADR-001: 文件系统作为 Wave 1 唯一存储层

状态：已采纳 | 2026-04-19

## 上下文

SEVO 需要持久化流水线状态、阶段记录和全部工件引用。存储层的选择直接影响部署复杂度、宿主适配成本和 Wave 1 交付速度。

## 决策

Wave 1 采用文件系统作为唯一存储层。所有状态和工件以 JSON + Markdown 文件形式落盘，目录结构为 `pipelines/{id}/state.json`、`pipelines/{id}/stages/`、`pipelines/{id}/artifacts/`、`ledger/`。

## 替代方案

| 方案 | 优势 | 放弃原因 |
|------|------|---------|
| SQLite | 事务支持、查询能力强 | 增加外部依赖，宿主适配成本高 |
| 对象存储（S3 等） | 天然支持多实例 | Wave 1 单机场景不需要，引入网络依赖 |
| 内存 + 定期快照 | 读写快 | 主会话中断丢失状态，违反 NFR-5.7 |

## 后果

- 零外部依赖，宿主只需提供文件读写能力即可接入。
- 不支持并发写入同一流水线，Wave 1 限制单实例运行。
- Wave 2 需要引入文件锁或迁移到数据库以支持并发场景。
- 工件 Schema 包含版本号，便于后续存储层迁移时做数据兼容。
